# Tectonic Venue Explorer

Public deployment of the Tectonic Wintercircus and De Vooruit visualization.

The standalone website preserves its sandboxed iframe and Content Security Policy. It includes three Concertzaal event layouts, venue-specific reference drawings, floor controls and street entrance guidance.

This is an orientation model with approximate dimensions. Some upper-floor footprints and proposed event fixture positions are schematic. Source references and qualifications are included in the visualization.
